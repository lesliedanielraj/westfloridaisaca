# Credential logos

Put ISACA's official logo for a credential here, named by its code: `CISA.png`, `CISM.svg`,
`AAIA.webp` and so on (`.png`, `.svg`, `.webp` or `.jpg`). The Credentials tab shows a logo
wherever it finds one and the plain code where it does not. Rebuild the site afterwards
(`npm run build`).

The logos are ISACA trademarks. Use the files ISACA supplies to chapters, unaltered, and follow
ISACA's brand rules for them. They are not committed: `.gitignore` keeps image files in this
folder out of the repository, which is public.
